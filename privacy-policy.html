Политика конфиденциальности Transkribe

Дата последнего обновления: 15 марта 2026 г.

Transkribe — расширение для Google Chrome, которое записывает аудио из вкладки браузера и микрофона, транскрибирует его с помощью OpenAI Whisper и создаёт AI-резюме встречи через Anthropic Claude.

Какие данные мы собираем

  • Аудиозапись встречи. Аудио захватывается только во время активной записи, инициированной пользователем, и нигде не сохраняется постоянно — оно передаётся в API и сразу удаляется из памяти.
  • API-ключи. Ключи OpenAI и Anthropic, введённые пользователем, хранятся локально в chrome.storage.local только на устройстве пользователя и никуда не передаются расширением.
  • Данные о спикерах. Имена участников встречи (из интерфейса Google Meet / Яндекс Телемост) используются только для диаризации транскрипта и не сохраняются после закрытия браузерной сессии.

Передача данных третьим сторонам

  • OpenAI (Whisper API). Аудиофайл отправляется на api.openai.com для транскрибирования. Применяются политика конфиденциальности OpenAI.
  • Anthropic (Claude API). Диаризованный транскрипт отправляется на api.anthropic.com для генерации резюме. Применяются политика конфиденциальности Anthropic.

Расширение не собирает и не передаёт данные ни в какие другие сервисы.

Хранение данных

Расширение не использует удалённые серверы для хранения пользовательских данных. Весь транскрипт и результаты резюме хранятся только локально в памяти браузера и очищаются при перезагрузке страницы.

Права пользователей

Вы можете в любой момент удалить API-ключи на странице настроек расширения или полностью удалить расширение, что удалит все связанные локальные данные.

Контакт

По вопросам конфиденциальности создайте issue в репозитории проекта.
